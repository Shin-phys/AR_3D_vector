# 引き継ぎ（3D／AR）

2026-10-13 時点。新しいチャットの冒頭にこのまま貼れば続きから始められる。

## 1. 何を作っているか

運動ベクトル可視化の **3D 版**。動画から 3D の軌跡を復元し、空間に固定した3Dストロボとベクトルを回り込んで見る。
2D 版（ホドグラフ）の姉妹アプリ。生徒は矢印を描かず、視点を動かして観察する。核の教材は「円運動の影が単振動になる」。

- 作業フォルダ：`~/Webアプリ開発/ARベクトル`（Mac）
- リポジトリ：`github.com/Shin-phys/AR_3D_vector`（GitHub Pages で公開）
- 技術：素の JS、ビルドなし。名前空間 `HG`＋IIFE（2D と同じ）。3D は three.js を `vendor/` に同梱（CDN から読まない）
- **設計と罠は README.md に全部ある。まず README を読むこと。** 仕様は `docs/3D仕様.md`

## 4. 壊してはいけない設計（README の「変えてはいけない約束」の要約）

1. 共有モジュール（`SHARED.txt`）はこのリポジトリで編集しない。ホドグラフで直して `tools/sync-shared.sh` で取り込む
2. 座標系：y 上、x 画面の右、z 手前、原点は紙の角 A
3. 半コマずれ：速度 v[k] は r_k→r_{k+1}、Δv a[k] は r_{k+1}
4. モデルを当てはめない（円も正弦波も）。平滑化しない
5. ビューアと AR は `content.js` の同じ中身を使う。部品は全部 Mesh（線や文字は USDZ に載らない）
6. ボタン名・ガイド文に結論を書かない。解説は Δv と壁の影を生徒が出したあとだけ
7. ✓ は生徒の行為にだけ
8. 貼り付くブロックに何も足さない（3D は動画のキャンバスと入れ替える）
9. 視点は瞬間移動させない
